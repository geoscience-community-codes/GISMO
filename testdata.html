What is GISMO demo data?

This directory contains curated real seismic datasets in multiple industry-standard formats, used by GISMO for:

  • Unit testing
  • Cookbooks and tutorials
  • Training workflows
  • Regression testing across releases
All data are now stored externally to the main GISMO repository and accessed via the global MATLAB variable TESTDATA.

Directory listing

  • css3.0
    Relational databases in Center for Seismic Studies 3.0 (CSS) schema format, used by Antelope and regional/nuclear monitoring systems. Includes realistic event, origin, and waveform descriptor tables.
    • avodb20080712, avodb200903
    • dbredoubt200903
    • dbokmok20080712
    • plutons
    • rtdb200903
    • Associated *.event, *.origin, *.wfdisc, *.snetsta, *.schanloc tables
  • matfiles
    Prepackaged MATLAB-native datasets for fast testing and demonstrations.
    • Catalog/: great earthquakes, tectonic plates, Redoubt and Tohoku catalogs
    • threecomp.mat: three-component waveform tests
    • correlation.mat: waveform correlation examples
    • mastercorr.mat: master event correlation tests
    • augustine_event_waveforms.mat: real volcano event waveforms
    • plutons_waveforms.mat: response and waveform examples
    • synthetic_waveforms.mat: controlled synthetic test cases
    • obspy.stream.*.mat: ObsPy–MATLAB interoperability datasets
  • miniseed_data
    Waveform data files in MiniSEED format.
    • Redoubt Volcano, Alaska (2009) pre-eruption examples
    • Stations: REF, RSO, RDN
    • Modern IH/II network MiniSEED examples
  • rsam
    Real-time Seismic Amplitude Measurement (RSAM) files in legacy binary format.
    • Montserrat volcano RSAM time series (1996–1997)
    • Additional 2015 RSAM examples
  • sac_data
    Waveform data files in SAC format.
    • IU.COLA broadband examples
    • Three-component Hawaii broadband example (POHA)
    • REF volcano waveform (2009)
  • sacpz
    Pole-zero instrument response files.
    • SACPZ.IU.COLA.10.BHE
    • SACPZ.IU.COLA.10.BHN
    • SACPZ.IU.COLA.10.BHZ
  • seisan_data
    SEISAN observatory databases from the Montserrat Volcano Observatory.
    • REA/MVOE_: event metadata ("S-files")
    • WAV/MVOE_: waveform files in SEISAN format
  • obspy
    Interoperability support for Python ObsPy data exported to MATLAB.
